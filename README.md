# MeteoClubOnlineWebsite
"气象深高"网站

## 📖 项目简介
者是一个深圳市高级中学气象社制作的在线天气信息展示平台，提供校园天气监测，预警信息、天气预报查阅等功能。
页面链接：[气象深高 - 首页](https://smc-club.pages.dev/)

## 🌟 主要功能
- **在线晴雨表**：实时显示中心校区定位下的天气数据和趋势预测，及时了解全市预警信息。
- **十天天气预报**：显示未来 10 天的天气预报
- **实用工具箱**：整合高频使用的气象相关资源和友情链接
